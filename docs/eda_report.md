## 9. What this means for the pipeline

- The sample covers only 7 days, so weekly patterns cannot be learned from it and forecast
  metrics come from few test hours. Treat the evaluation as a demonstration of method.
- The generated sample is clean: no row breaks a validation rule and there are no duplicates. The rules and the duplicate check therefore only fire on replays (every repeated event is skipped) and on bad input sent to the API.
- Because the generator is seeded, this report is reproducible byte for byte apart from the timestamp.
